# Porto Marghera Cohort Study

### Project Contents

- `Cohort_Analysis.do`: Stata script for data preparation, survival analysis, rate estimation, Mantel-Haenszel comparisons, and standardized-rate calculations.
- `Cohort_Study.pdf`: Report describing the methodology and results.

## Methods

The analysis includes descriptive statistics, Kaplan-Meier curves, crude and stratified mortality rates, Mantel-Haenszel rate ratios, and indirect standardization.
