# Porto Marghera Cohort Study

### Project Contents

- `porto_marghera_EN.do`: Stata script for data preparation, survival analysis, rate estimation, Mantel-Haenszel comparisons, and standardized-rate calculations.
- `Porto_Marghera_Cohort_Study_EN.pdf`: English report describing the methodology and results.
- `Porto_Marghera_LaTeX_EN.zip`: complete LaTeX project for the English report.

## Methods

The analysis includes descriptive statistics, Kaplan-Meier curves, crude and stratified mortality rates, Mantel-Haenszel rate ratios, and indirect standardization.
